# VALORANT Archipelago 0.6.0

Released October 7, 2026

## New

- **Kingdom Credits weapon shop.** Kingdom Credits, the filler item, are now a currency. In the client's new **Shop**
  tab, or with `/rent <weapon>`, you can rent a weapon you haven't unlocked for one match.
  - Kills with it count, and Strict enforcement doesn't void the match for it.
  - A rental covers your next match that counts: one that starts after you rent, with an unlocked agent, in an allowed
    mode. Rent during agent select and it covers that match; rent mid-match and it covers the next one.
  - Unused rentals can be refunded (Shop tab or `/refund <weapon>`). `/shop` lists your credits, prices and rentals.
  - Your balance shows next to Radianite at the top of the client ("KC: 5").
  - Purchases are saved on the Archipelago server, so they survive restarts. If the client wasn't running during the
    match, the rental still applies when it catches up on your match history.
  - Rentals are never needed to progress: the logic only expects weapons you've unlocked.
- **New options:** Weapon Shop (on by default) and Rental Prices, per weapon type (Sidearm 1, SMG 2, Shotgun 2,
  Heavy 3, Rifle 4, Sniper 4). The spoiler log lists the prices.

## Bridge

- **The agent-select overlay is now drawn inside the game** by Overwolf's overlay package, so it shows even in
  exclusive Fullscreen. The always-on-top window is gone: when the in-game overlay isn't attached, nothing is shown.
  - The overlay package attaches to VALORANT when the game launches, or late if the game is already running. It uses
    the same Overwolf credentials as the game events.
  - It's optional: `SHOW_OVERLAY=false` keeps the package from attaching to the game at all.
- **The weapons list shows rentals** with a "Rented" tag, and your Kingdom Credits next to the weapon count.

## Updating

Install the new `valorant.apworld` and regenerate (the prices are set when the multiworld is generated). Run
`npm run pack` again for the bridge.
