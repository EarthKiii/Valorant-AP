# VALORANT Archipelago 0.3.0

Released October 5, 2026

## New

- **Short Mode Thresholds (%):** Swiftplay and Spike Rush matches are much shorter, so their Kill, Assist and Trade
  thresholds can be lowered to this percentage (rounded up). At 75, a 20-kill check needs 15 kills there. 100 turns it
  off (the default in this version).
  - Kills, assists and trades in those modes count extra toward the regular thresholds (×1.33 at 75), so mixing modes
    adds up fairly.
  - The lowered thresholds are listed in the spoiler log, when the client connects, in `/progress` and in the bridge
    window's agent card. The match-start message and the bridge's match banner say when they apply.

## Bridge

- **`npm run pack`** builds a ready-to-run copy in `bridge/dist/VALORANT Bridge/`, with a shortcut to start it. It
  doesn't need Node.js, and live game events keep working. Its settings and credentials are in `app\.env`.

## Updating

Install the new `valorant.apworld` and regenerate to use the new option.
