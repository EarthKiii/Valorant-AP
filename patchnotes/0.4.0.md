# VALORANT Archipelago 0.4.0

Released October 5, 2026

## Changed

- **Performance Score replaces ACS.** VALORANT patch 13.06 replaced ACS with a 0–500 Performance Score, so the ACS
  checks are now Performance checks.
  - New option **Performance Score Thresholds** (250 and 350 by default). Around 250 is an average game; 350+ is a
    standout one.
  - Like ACS, it uses your best finished match with the agent, and the checks arrive once Riot publishes the match.
  - Only modes with a Performance Score can earn these checks: Competitive, Unrated, Swiftplay and Premier.
  - The ACS Thresholds option is gone, and Excluded Stats lists Performance instead of ACS.
- Worlds generated before this version keep their ACS checks, and the client still tracks ACS for them.

## Known issue

- Riot's match data stores the Performance Score under a placeholder name. If a future patch renames it, Performance
  checks stop progressing (they never count a wrong value) until the client is updated.

## Updating

Install the new `valorant.apworld` and regenerate. In your YAML, replace `acs_thresholds` with
`performance_thresholds`; an old `acs_thresholds` line only causes a warning.
