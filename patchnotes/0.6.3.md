# VALORANT Archipelago 0.6.3

Released October 7, 2026

## Changed

- The client's old `--bridge-port` option is gone; use `--companion-port`.

## Companion

- **Setup exe:** `npm run sfx` builds `VALORANT Companion Setup.exe`, one file that installs or updates the companion
  without Node.js.
  - It installs to `%LOCALAPPDATA%\Programs\VALORANT Companion` (no admin rights needed), with shortcuts on the
    Desktop and in the Start Menu.
  - Updating replaces the old files but keeps your settings and credentials (`app\.env`). If the companion is
    running, it asks you to close it first.
  - If no Overwolf credentials are set yet, it opens the settings file in Notepad, then offers to start the companion.
  - It never contains your credentials, so it's safe to share. Each person needs their own Overwolf developer
    credentials.
  - It isn't signed, so Windows SmartScreen may warn on the first run (**More info** → **Run anyway**).

## Updating

Reinstall `valorant.apworld` if you start the client with `--bridge-port` (switch to `--companion-port`). No need to
regenerate.
