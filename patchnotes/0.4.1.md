# VALORANT Archipelago 0.4.1

Released October 5, 2026

## New

- **Agent-select overlay** (with the bridge): during agent select, a small note at the top of the screen shows:
  - your unlocked agents, until you hover one;
  - a red warning when the agent you hover or lock in wouldn't count (still locked, or not in your world), or when the
    game mode doesn't count;
  - a green "counts" once you're on an agent that does.
- In this version the overlay was a normal always-on-top window, so it only showed with VALORANT in Windowed
  Fullscreen. 0.6.0 replaced it with an in-game overlay.
- During agent select, the client now checks your pick every second.

## Bridge

- **The progress window is rebuilt with Svelte.** It looks and works the same, and only redraws the parts that change.
  `npm start` and `npm run pack` build it automatically.
- New `.env` settings: `SHOW_OVERLAY=false` turns the overlay off, and `OVERLAY_TOP` moves it up or down.

## Updating

Reinstall `valorant.apworld`, then run `npm run pack` (or `npm start`) for the bridge. No need to regenerate.
