# VALORANT Archipelago 0.2.1

Released October 4, 2026

## Fixed

- **The client no longer crashes with "No module named winsound"** the first time it plays a sound (for example when
  an item arrives). The installed Archipelago doesn't ship that module; sounds now play another way, and a failing
  sound can never crash the client.

## Updating

Reinstall `valorant.apworld` and restart the Launcher. No need to regenerate.
