# VALORANT Archipelago 0.5.0

Released October 5, 2026

## Changed

New default settings, so the Options Creator opens with them:

| Option | Before | Now |
|---|---|---|
| Starting Agents | 1 | 3 |
| Kill Thresholds | 10, 25, 50 | 10, 15, 20 |
| Assist Thresholds | 5, 15, 30 | 5, 10, 15 |
| Clutch Thresholds | 1, 3 | 1, 2 |
| 3K Thresholds | 1, 3 | 1, 2 |
| Win Thresholds | 1, 3 | 1, 2 |
| Short Mode Thresholds | 100 (off) | 75 |

## Updating

YAMLs that already set these options are unaffected. Install the new `valorant.apworld` and restart the Launcher so
the Options Creator picks up the new defaults.
