# VALORANT Archipelago 0.2.0

Released October 4, 2026

## New

- **Wins checks:** one check per number of matches won with the agent (1 and 3 by default). Wins always add up across
  matches, even in Single Match mode.
- **ACS checks:** a check when you finish a match at or above an Average Combat Score (175 and 225 by default). Like
  K/D, it uses your best single match. ACS isn't in the live feed, so these checks arrive once Riot publishes the
  match.
- **Skirmish** is now a choice in Allowed Queues (off by default).

## Changed

- **Gauntlet (Ability Draft) matches never count.** Riot records every player there as the same generic character,
  so there's no agent to credit.

## Fixed

- Skirmish and Gauntlet map names display properly.
- The first match-history sync saves your progress once, instead of after every match.

## Bridge

- `npm start` reads your Overwolf credentials (`OW_CLI_EMAIL`, `OW_CLI_API_KEY`) from `bridge/.env`. Values set in
  your shell still win.
- `npm start` works from terminals that set `ELECTRON_RUN_AS_NODE`, such as VS Code's.

## Updating

Install the new `valorant.apworld` and regenerate your multiworld to get the Wins and ACS checks.
