# VALORANT Archipelago 0.1.0

Released October 4, 2026 · first release · requires Archipelago 0.6.4 or newer

## The world

- **Agents and weapons are items.** A match only counts with an agent you've unlocked. Kills with a weapon you
  haven't unlocked don't count (the Classic, knife and abilities always do).
- **Checks are stat milestones per agent:** Kills, Assists, Trades, Clutches, Aces, 3Ks and K/D, each with its own
  list of thresholds (up to 10 per stat).
- **Goal:** collect enough Radianite Crystals (12 of 15 by default). Kingdom Credits are the filler item.

## Options

- **Agent Pool / Agent Count / Starting Agents:** which agents can appear, how many do (6), and how many you start
  with (1).
- **Weapon Unlocks / Starting Weapons:** weapons as items, and how many random primaries you start with (1).
- **Weapon Enforcement:** Kills Only (locked-weapon kills are ignored), Strict (using a locked weapon voids the match)
  or Off.
- **Weapon Logic:** Standard (higher tiers expect more primary weapons) or Relaxed (only the agent is ever required).
- **Progress Mode:** stats add up across matches (Cumulative) or must be reached in one match (Single Match).
- **Thresholds:** Kills 10/25/50, Assists 5/15/30, Trades 2/5/10, Clutches 1/3, Aces 1, 3Ks 1/3, K/D 1.0/1.5.
- **Excluded Stats** (Aces by default), **Allowed Queues** (Competitive, Unrated, Swiftplay, Spike Rush, Premier),
  **Trade Window** (5 seconds), **Radianite Count** (15) and **Radianite Required** (80%).

## The client

- Open **Valorant Client** from the Archipelago Launcher. It reads your session from the Riot Client that's already
  running, so it needs no setup of its own.
- In agent select it warns you, with a sound, when you hover or lock a locked agent. When a match starts, it says
  whether it counts.
- It fetches the official result seconds after a match ends, and checks your match history every 2 minutes for
  anything it missed. Only matches that start after you first connect count.
- Your progress is saved on the Archipelago server.
- Commands: `/valorant`, `/progress`, `/unlocks`, `/sync`, `/region`, `/sounds`.

## Live-stats bridge (optional)

- A small app built on ow-electron, Overwolf's build of Electron. It runs without the Overwolf client and loads only
  Overwolf's game events.
- With it, kills, 3Ks, aces, trades and clutches send checks the moment they happen. Riot's official numbers replace
  the live ones once the match is published.
- It needs free Overwolf developer credentials.
