# VALORANT Archipelago 0.6.1

## Changed

Weapon rentals cost one more Kingdom Credit:

| Type | Before | Now |
|---|---|---|
| Sidearm | 1 | 2 |
| SMG | 2 | 3 |
| Shotgun | 2 | 3 |
| Heavy | 3 | 4 |
| Rifle | 4 | 5 |
| Sniper | 4 | 5 |

## Updating

Install the new `valorant.apworld` and regenerate. YAMLs that set their own Rental Prices keep them.
