# VALORANT Archipelago 0.4.2

Released October 5, 2026

## Changed

- **Agent select follows your pick through the bridge's live game events.** The overlay and the warnings react the
  moment your pick changes, without asking Riot's servers.
- Asking Riot is back to every 3 seconds, and only as a fallback: when live events are off, or until they report your
  pick. The client's log says which one it's using in each agent select.

## Updating

Reinstall `valorant.apworld`. No need to regenerate.
