# VALORANT Archipelago 0.6.2

Released October 7, 2026

## Changed

- **The "bridge" is now the Companion app.** It does more than pass game events along (live stats, the progress
  window and the in-game agent-select overlay), so the name now says that.
  - The folder is now `companion/`, and `npm run pack` builds `dist/VALORANT Companion/` with a **VALORANT
    Companion** shortcut.
  - The client says "Companion app connected" instead of "Live-stats bridge connected", and `/valorant` reports the
    Companion app's status.
  - The client's port option is now `--companion-port`. `--bridge-port` still works.

## Updating

- Reinstall `valorant.apworld`. No need to regenerate.
- Run `npm run pack` in `companion/` and use the new **VALORANT Companion** shortcut. The old
  `dist/VALORANT Bridge/` copy can be deleted.
- The Companion starts with a fresh cache, so it downloads the agent and weapon icons once more on its first run.
  The old cache in `%APPDATA%\valorant-ap-live-bridge` (about 15 MB) can be deleted.
